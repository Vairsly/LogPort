# LogPort 版本发布记录

本文档记录 LogPort 各版本的发布内容，便于部署对照与回溯。版本号采用语义化版本（MAJOR.MINOR.PATCH）。

当前版本：**1.0.0**（分支 `1.0.0-release`，2026-09-26）

> **冻结说明：** `1.0.0` 是当前「SSH + `docker logs`」采集方案的最后一个正式版本。后续版本若更换日志获取方式，将另开主版本，不再在本线上演进。

---

## 1.0.0 — 2026-09-26

对应分支：`1.0.0-release`  
对应提交：`82a270a`（与 `main` 当时快照一致）

将 0.2.x 前后端分离成果定为 **1.0.0 正式版**，并冻结本代采集实现。

### 定位

- 通过 SSH 在目标机执行受控 `docker logs`，按服务器 / 容器 / 时间范围导出日志。
- 本代能力到此为止：不再作为后续采集架构的迭代基线。
- 需要继续使用 `docker logs` 方案时，请基于 `1.0.0-release` 分支部署或打补丁。

### 本代完整能力

- 管理员登录（会话 Cookie + CSRF）。
- 多服务器管理：SSH 凭据加密、容器白名单、连接测试、主机指纹确认。
- Worker 异步导出；任务最长 24 小时；产物保留 24 小时后清理。
- Vue 3 SPA + Flask API 分离部署；Docker Compose / `dev.sh` 开发与发布。

### 相对 0.2.1

- 功能与代码与 `82a270a` 相同，仅提升为正式主版本并声明采集方案冻结。
- 退出登录按钮、部署文档与 `scripts/rebuild-python-sqlite.sh` 已包含在内。

### 升级说明

- 从 0.2.x 升级：无库表或接口变更，拉 `1.0.0-release` 后重建前端 / 镜像即可。
- 后续若采用非 `docker logs` 采集，视为 2.x，需单独评估数据与部署迁移。

## 0.2.0 — 2026-09-24

对应提交：`b1f7436` 前后端分离改造

这是一次架构级发布，将单体 Flask 模板应用拆为 **Vue 3 + Vite 前端** 与 **Flask API / Worker 后端**。

### 新增

- `frontend/`：Vue 3 单页应用（登录、仪表盘、服务器管理、导出任务、任务列表、Toast）。
- `backend/`：原 `log_exporter`、入口、测试与依赖整体迁入。
- 设计文档：`doc/design.md`、`doc/api.md`、`doc/frontend.md`。
- 部署文档：`deploy.md`；开发脚本：`dev.sh`、`scripts/dev.sh`。
- Docker 多阶段构建与 Compose 配套更新。

### 变更

- Web 不再由 Flask 渲染 HTML，改为静态 SPA + `/api` JSON。
- 会话 Cookie + CSRF（`X-CSRF-Token`）作为前后端鉴权约定。
- README 改为前后端分离后的快速开始与文档索引。

### 移除

- `log_exporter/templates`、`log_exporter/static`、`log_exporter/views.py`。
- 根目录 `plan.md`。

### 影响范围

- 目录结构、Docker 镜像、本地启动方式全部变化。
- 生产访问默认 `http://127.0.0.1:9090`；本地开发前端 `http://127.0.0.1:5173`。

### 升级说明

1. 备份数据目录与 `CREDENTIAL_KEY`。
2. 按新仓库结构拉取代码，复制 `.env.example` 并核对环境变量。
3. 使用 `./dev.sh deploy` 或 `docker compose up -d --build` 重新构建。
4. 旧单体镜像不可直接热替换，需完整重建。

## 0.1.0 — 2026-08-05

对应提交：`f21d935` 初始化日志查看服务

首个可用版本。

### 功能

- 管理员登录（会话鉴权）。
- 多服务器管理：SSH 地址、凭据加密存储、容器白名单、连接测试与主机指纹确认。
- 按服务器 / 容器 / 时间范围创建 Docker 日志导出任务（最长 24 小时）。
- Worker 通过 SSH 执行受控 `docker logs`，完成后提供下载。
- 任务失败展示脱敏错误摘要；生成文件保留 24 小时后自动清理。
- SQLite 存储、Docker Compose 部署、基础自动化测试。

### 安全要点（首发即具备）

- SSH 凭据加密（`CREDENTIAL_KEY`）。
- 主机指纹校验，变更后拒绝连接直至确认。
- 容器白名单，限制可导出范围。
